# 使用指南

[English](../en/user-guide.md) | [文档首页](README.md)

本指南覆盖桌面端日常流程。请先按[快速开始](getting-started.md)完成安装和设备准备；全部已实现字段与服务见[功能参考](features.md)。

## 连接与切换设备

设备总览是默认工作区。它按物理设备归并 USB 与已认证 Wi-Fi 传输，集中显示连接阶段、活跃资源需求、最近活动和可复制的会话错误；设备条目不会建立视频、音频或控制 WebSocket。按提示解锁并信任设备，连接所需传输，再用**打开控制**进入实时设备工作区。

顶部紧凑连接中心可在任意工作区执行相同的生命周期操作。同一设备的 USB/Wi-Fi 是不同选项，但同一物理设备只能有一个活动传输。

多台设备可以保持连接。选择另一台设备只切换可见工作区，不会断开已有会话。连接阶段和错误按设备显示；失败会话使用重新连接，仅在确实需要重新配对时撤销信任。元数据超时不一定表示媒体会话失败，可恢复元数据会在后台重新加载。

## 控制设备

设备工作区包含实时画面、直接触控、串流状态、显示控制、硬件按钮和功能工具。右键画面发送 Home。选择**映射**把配置按键转换为触摸/硬件操作，选择**键盘直通**转发物理 HID 按键。两种模式都支持鼠标直接触控；键盘直通会绕过按键映射，直接使用原始多点触控通道。模式、页面、焦点、全屏或连接变化都会释放按住的输入。

指针坐标限制在实际显示的手机画面内，不包含黑边，并跟随方向。最多支持五个同时触点。文本操作把有界 Unicode 文本写入设备剪贴板并发送粘贴，使用前先聚焦可编辑区域。

硬件与功能按钮组可根据空间调整布局。在专注/全屏显示中可停靠到边缘，左右停靠使用竖列，也可吸合为紧凑组合。布局会持久化，设置中可恢复默认。空间不足时硬件按钮保持最高优先级。设备专注显示与操作系统全屏是两个不同控制。

## 管理画面

使用适配和缩放调整画面，空间不足时隐藏侧边栏。静止画面不会只因像素不变而被判断为串流停止；健康状态根据连接与媒体进度判断。传输实际停滞时，应复制完整错误并使用重新连接，不要重复创建新会话。

截图使用无损设备服务 fallback，与 WebCodecs 视频帧无关。可选性能 HUD 显示在设备工作区上方，条目可在设置中配置。

排查主机输入时，可从设备工具栏或设置打开**注入触摸调试**。它会叠加当前浏览器控制会话生成的最终触点帧，显示触点 ID、按下/移动/释放轨迹、显示坐标、方向转换后的原生坐标及活跃映射 ID。该功能默认关闭，只报告主机生成的触点帧，不会反向读取 iOS 的真实触摸事件。

## 使用按键映射

打开按键映射，创建或选择 profile，选择实时/截图背景，添加控件，分配唯一按键，并在映射模式测试。Profile 可绑定 App bundle ID 和准确设备画面分辨率，因此同一 App 可以分别配置 iPhone/iPad 布局。导入时需明确选择 DeviceHub Mask、scrcpy-mask 或 PlayCover 来源。

编辑器支持撤回/重做、在有效范围内切换控件类型、硬件按钮快捷键、导入/导出和打开配置目录。控制器语义、触点所有权、文件格式与排障见[按键映射指南](key-mapping.md)。

## 检查和管理设备

检查器包含设备身份、电池/存储/地区信息、App、描述文件、崩溃报告、App 容器和支持的管理操作。Apple 独立暴露各项服务，因此控制可用时，某些可选数据仍可能不可用。

App 视图可以检查已有 App、启动/停止/重启受支持 App、显示有界签名/运行元数据、带会话控制台启动开发 App、移除确认可卸载 App，并打开允许的 App 存储。项目明确不能安装、侧载、签名、注入或升级 App。

App 存储通过 House Arrest 访问单个 App 的 Documents 或允许的容器；AFC 工作区访问设备级公共媒体容器。两者根目录不同，权限由 iOS 决定。传输显示进度并可取消，拒绝不安全路径和特殊条目，临时数据清理完成前保持忙碌状态。

描述文件操作校验有界 `.mobileprovision` 数据，信任/移除需要确认，且不是 App 安装通道。崩溃报告可列出和导出，删除必须确认。诊断和抓包产物可能含隐私数据，应按敏感文件处理。

## 性能、日志与诊断

性能工作区仅在需要时启用采样，显示设备提供的规范化 CPU、内存、图形、能耗、进程、网络接口和服务健康观测。这些是设备观测，不是主机“活动监视器”的百分比。部分 DVT 服务需要开发者模式，也可能被 iOS 禁止。

设备日志优先使用结构化 Unified Log，失败时回退到 SyslogRelay。筛选和暂停在本地完成，高流量时有界缓冲可能丢弃旧条目。日志归档、sysdiagnose、备份、网络 PCAP 和 Bluetooth HCI 抓包都是有明确限制与隐私提示的显式长操作。报告错误时使用统一复制按钮，并附上相关 JSONL 运行日志片段。

## 虚拟定位与设备条件

虚拟定位优先使用 DVT，也可能使用兼容 legacy 服务。启动后会改变目标设备位置，直到停止或会话清理恢复真实定位。网络/温度条件用于开发诊断，测试后应重置。多设备下两者都只作用于目标设备。

## 设置与更新

设置管理语言、启动/更新通道、诊断、剪贴板、性能 HUD、设备视图偏好和工具条恢复默认。语言立即切换且不改写用户名称。诊断区显示 run ID、日志 filter 和日志目录；Debug 日志只影响当前运行，除非环境 filter 覆盖。

Stable 与 Nightly 是不同更新通道。用户接受桌面更新后，会先验证签名再安装并重启。版本与签名细节见 [CI、发布与更新](distribution.md)。

## 浏览器与 Agent 操作

同一套 UI 可由 headless 服务提供；宿主专用操作按能力限制，LAN 使用必须显式发布并使用 token。见 [Headless 服务](headless.md)。

Agent 通过内置 MCP 选择独立目标、截图、发送 HID、操作 App、等待状态、检查诊断，并可选使用 WDA 语义操作。MCP 不改变桌面选择。配置、安全和工具流程见 [MCP 自动化指南](mcp.md)。

## 故障处理

复制完整展示错误，记录所选设备与传输，再收集对应时间段运行日志。不要把撤销信任或删除配对数据作为第一步。[故障排查](troubleshooting.md)包含平台准备、远程配对 EOF、音频缺失、视频停滞、CoreDevice 错误、CPU 占用和更新失败处理。
