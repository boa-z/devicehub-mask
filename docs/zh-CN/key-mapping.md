# 按键映射使用指南

[English](../en/key-mapping.md) | [文档首页](README.md) | [使用指南](user-guide.md)

DeviceHub Mask 会把电脑的键盘和鼠标输入转换成 iPhone 或 iPad 上的 Universal HID 触点。一个已保存配置包含触控映射、iOS 硬件按键快捷键以及可选的 App 关联。本指南以当前实际运行时为准，同时明确说明哪些兼容字段可以导入导出、但目前尚不会执行。

## 开始前

- 连接并解锁已经信任的设备，先确认实时画面可以接受鼠标直接触控。
- 从主导航进入“按键映射”。需要更多画布空间时，可用标题栏按钮独立隐藏映射侧栏。
- 请在游戏实际使用的方向下制作配置。归一化坐标不会受到显示缩放影响，但竖屏布局不会自动变成可用的横屏布局。
- 测试物理按键时保持应用窗口聚焦。窗口失焦、切换页面或输入模式、进入全屏以及设备断开时，应用都会释放全部输入。

## 创建第一份可用配置

1. 选择已有配置或新建配置。配置名称长度为 1-80 个字符，只能包含字母、数字、`_` 和 `-`。
2. 保持“编辑”开启。在设备画面的准确目标位置点击右键并选择“单次点击”，也可以从检查器添加后把新控件拖到目标位置。
3. 选中控件，点击“键盘绑定”，再按下需要的物理按键或组合键。编辑器保存的是 `KeyboardEvent.code`，表示物理键位，而不是输入法合成后的字符。
4. 将触点 ID 设为 `0` 到 `4`。新建和复制会优先选择使用次数最少的身份，但可能同时触发的动作仍需人工检查。
5. 点击“保存”。保存只写入配置，不会自动激活一份非当前配置。
6. 点击“设为当前”，或在设备工作台的配置选择器中切换到这份已保存配置。
7. 在按键映射页测试前关闭“编辑”。编辑开启时会主动屏蔽按键映射和直接触控，避免编辑动作误操作设备。

保存当前激活配置后，运行时会立即使用新内容。编辑非当前配置时，应先保存再激活。设备工作台切换配置时始终读取磁盘中的已保存版本，因此未保存内容不会跟随切换。

## 画布与背景

编辑器会同时显示源画面尺寸和等比例适配后的视口尺寸。映射位置以可见设备画面内的 `0..1` 归一化坐标保存，不包含舞台空白区域。

- “实时”使用当前 WebCodecs 画面，并且只在该背景可见时请求视频。
- “截图”冻结当前已经解码的 Canvas。设备断开后，该截图在本次应用运行期间仍可用于离线编辑。
- “捕获”会替换冻结画面。“保存截图”会把当前实时或冻结 Canvas 写成 PNG；当前版本不能把外部 PNG 重新加载为编辑背景。
- “显示全部控制器范围与轨迹”会展示 Swipe、MultipleTap 路径和已配置的控制半径。关闭全局范围后，当前选中控件的范围仍会显示。
- 拖动控件节点可以移动主点；需要精确位置时使用百分比输入。序列点和施法中心在检查器中编辑。

旋转会改变画面宽高和坐标变换。如果游戏的横竖屏布局明显不同，应分别建立配置。

## 按键与组合键

一个按钮绑定可以是单键，也可以是组合键。组合中的全部按键都按下后映射才会生效。浏览器能够区分时，修饰键会保留左右物理身份。在绑定输入框中按 Backspace 或 Delete 可以清除绑定。

不要把同一个物理按键分配给多个触控映射。运行时会把该按键交给配置顺序中第一个生效的映射，并抑制后续映射。触控映射使用的按键也不能再分配给硬件按键快捷键，两个硬件按键同样不能共用快捷键；编辑器和后端都会拒绝这两类硬件冲突。

焦点位于按钮、输入框、选择器或其他表单控件时，运行时映射处理器会忽略按键；绑定输入框本身仍会捕获准备分配的按键。运行时测试前应点击设备画面。`Ctrl+Shift+K` 是输入模式切换保留快捷键，不应再分配给控制器。

## 检查器字段

| 字段 | 含义 |
| --- | --- |
| 名称 | 覆盖层和列表中显示的名称，不影响输入分发 |
| 类型 | 控制器行为；切换后会重建控制器并重置不兼容设置 |
| 位置 / 施法中心 | 当前方向下源画面中的 X/Y 百分比 |
| 触点 ID | `0..4` 的 Universal HID 身份；并发触点必须唯一 |
| 键盘绑定 | 一个物理按键，或要求全部成员同时按下的组合键 |
| 方向绑定 | 上下左右各自独立的 Button 组合键；导入的 JoyStick 轴是只读兼容数据 |
| 半径 / 范围 | 源画面像素，运行时会换算为归一化坐标；DirectionPad 分别设置水平和垂直范围 |
| 持续 / 间隔 / 等待 | 毫秒单位，用于点击、连点、滑动、序列或保存的 Script 元数据 |
| 灵敏度 | 相对于源画面宽或高的鼠标增量倍率 |
| 释放模式 | 可导入和编辑的施法元数据；当前运行时只有随主绑定松开而释放的普通行为可靠 |
| 动作序列 | 有序归一化点位；MultipleTap 还保存每点持续时间及其前置等待 |
| 脚本字段 | 保存在配置和导出中的兼容文本；当前版本绝不会执行 |

修改字段只会编辑内存中的配置，必须点击“保存”才能持久化。类型选择器可在确认后将控制器重建为另一类型。转换会保留 ID、名称、位置及兼容的按键绑定和触点字段，目标类型专属设置则从有效默认值开始；滑动路径、施法专属选项、FPS 触控模式或 Script 文本等不兼容数据会被丢弃。旧版“按键”和“方向盘”映射也可通过同一选择器升级为“单次点击”和新版“方向盘”。

点击配置工具栏中的文件夹按钮，可以打开保存按键映射 JSON 文件的本地应用目录；目录不存在时应用会先创建它。通过下载菜单导出的文件是保存到用户所选下载位置的独立副本。

配置工具栏提供针对未保存编辑的撤销和重做按钮。在设备画面获得焦点时，使用 `Ctrl+Z` / `Cmd+Z` 撤销，使用 `Ctrl+Shift+Z`、`Cmd+Shift+Z` 或 `Ctrl+Y` 重做。文本输入框获得焦点时保留系统原生编辑快捷键，此时可通过工具栏按钮撤销完整配置修改。连续输入和拖动控制器会合并为有意义的单个历史步骤；加载其他配置时会重置历史，撤销不会跨越配置边界。

## 触点 ID 与并发输入

Universal HID 每份 report 最多包含五个触点，身份范围是 `0` 到 `4`。配置可以保存超过五个映射，永远不会同时使用的映射也可以复用身份。如果两个生效映射占用同一个身份，只有配置顺序中的第一个映射拥有触点并显示高亮。按住鼠标直接触控时也会占用一个可用身份。

对于“移动 + 两个技能”这类组合，所有可能同时按住的动作都应使用不同触点 ID。FPS 控件导入的双触点字段会为兼容性保留，但当前 FPS 运行时只输出主触点。

## 控制器参考

| 控制器 | 当前运行行为 | 重要限制 |
| --- | --- | --- |
| 单次点击 | 完整绑定保持按下时，最多在 `duration` 时间内按住一个触点 | 提前松键会立即释放；持续按键不会重复点击 |
| 连续点击 | 按键保持期间，按 `duration` 按下、按 `interval` 释放并循环 | 间隔应为正数，最终能否识别仍取决于设备和游戏 |
| 多段点击 | 按顺序执行一次点位序列，并应用每点等待与持续时间 | 序列结束后继续按住也不会循环 |
| 滑动 | 在 `duration` 内沿有序点位插值移动 | 到达最后一点后会保持按下，直到释放绑定 |
| 方向盘 | 将 Button 类型的上下左右组合转换为经过对角线归一化的拖动 | 导入的 JoyStick 轴绑定只保留、不执行 |
| 鼠标施法 | 按住主绑定，并按横纵缩放参数跟随鼠标增量移动触点 | 高级释放、中心、半径、随机化和脚本钩子语义尚未完整执行 |
| 方向施法 | 按住主绑定，并通过 Button 方向绑定在拖动半径内偏移 | JoyStick 轴、释放模式、阻塞、随机化和脚本钩子仅作兼容保留 |
| 取消施法 | 释放当前按住的 MouseCastSpell 与 PadCastSpell 绑定 | 自身不输出触点；应使用单键，因为组合键任一成员都可能触发该特殊动作 |
| 视野观察 | 按住时使用 X/Y 灵敏度随鼠标增量移动触点 | 运行时不限制 `max_radius`，也不执行随机化和脚本钩子 |
| FPS 视角 | 按住时使用 X/Y 灵敏度随鼠标增量移动触点 | 尚未实现指针锁定、最大偏移、间隔和双触点策略 |
| 开火 | 按住时使用 X/Y 灵敏度随鼠标增量移动触点 | 尚未实现 `preserve_fps_control`、随机化和脚本钩子 |
| 原始输入 | 释放映射输入并把应用切换到“键盘透传” | 自身不输出触点；应使用单键，因为组合键任一成员都可能触发该特殊动作 |
| 脚本 | 保存并往返导出按下、保持和释放脚本文本 | 尚未实现脚本执行，不能用于实际控制 |

鼠标驱动型控制器使用普通 WebView 指针移动，当前没有无限相对移动的指针锁定，指针到达窗口边缘后将停止继续移动。导入的随机偏移、脚本钩子及上表未列为生效的字段只是数据兼容能力，不代表运行时承诺。

## 硬件按键快捷键

在映射检查器中打开“硬件按键快捷键”，可以绑定主屏幕、锁屏、音量增加、音量降低、静音、Siri 和 Action。快捷键会分别发送按下与释放，因此 Siri 等操作可以保留按住时长。使用 Backspace 或 Delete 清除快捷键。

硬件快捷键随配置保存。设备工具栏始终独立提供相同的七个命令，不依赖快捷键。窗口失焦或切换模式时会释放所有仍按住的硬件按键。

## 编辑、映射与键盘模式

- “编辑开启”：移动和配置控件；按键映射与设备直接触控均关闭。
- “编辑关闭 + 映射”：物理按键运行当前配置，硬件快捷键可用，鼠标可直接触控设备。
- “键盘透传”：禁用触控映射和硬件快捷键，把支持的物理 HID 键盘按下/释放直接发送到 iOS。

使用 `Ctrl+Shift+K` 可以在“映射”和“键盘透传”之间切换。RawInput 的绑定按下时也会执行同样的切换。物理 HID 输入不会生成输入法组合后的 Unicode 文本；中文和其他 Unicode 文本应使用设备工具栏的粘贴操作。

## 配置管理

配置是保存在应用数据目录中的校验 JSON 文件。配置工具栏支持保存、激活、新建、复制、重命名、删除、App 关联、导入、导出和浏览在线仓库。

- 新建配置为空。复制会复制映射和硬件快捷键，但会主动清除 App 关联。
- 重命名会保留映射和关联；重命名当前配置后仍保持激活。
- 当前配置不能删除，应先激活另一份已保存配置。
- 每份配置最多包含 512 个映射和 32 个唯一且合法的 Bundle ID。只要存在 App 关联，配置就必须同时保存一个明确的目标画面分辨率。
- 导入配置会保存并打开供编辑，但不会自动激活。

## 在线按键映射仓库

在配置工具栏中选择“浏览在线配置”，即可打开官方目录。在线目录只是下载来源，不是配置同步服务：它不会替换已有本地配置；编辑、保存、激活和离线使用仍全部基于本地配置目录。

- “刷新”会通过 HTTPS 拉取当前目录，并保存已经校验的本地缓存。刷新失败时，如有上次成功的缓存，仍会显示缓存内容。
- 点击“仓库”可以保存另一个 HTTPS 目录 JSON 地址，也可以恢复官方地址。所选地址仅保存在本地，并使用独立缓存；它不会修改或同步本地配置。
- 可按配置名、Bundle ID 或设备目标搜索；也可选择已安装 App 的 Bundle ID，以及当前设备或目录声明的设备目标来缩小结果。选择设备目标时，条目的画面宽高、方向和可选 Apple 产品型号必须与该目标完全匹配；选择“全部仓库设备”即可不按设备筛选。
- 选择“下载”后，应用会校验目录记录的文件大小和 SHA-256、校验原生 `version: 2` 配置，并以不覆盖现有配置的本地名称写入后打开编辑器。
- 下载绝不会自动激活。请检查映射、按需保存修改，并在准备好后点击“设为当前”。

内置来源是公开的 [DeviceHub Mask Keymaps 仓库](https://github.com/boa-z/devicehub-mask-keymaps)。自定义地址必须是没有内嵌凭据的 HTTPS 目录文档地址。目录匹配只是兼容性提示，游戏界面可能变化，使用前仍应自行验证映射。

## 将配置关联到 App

打开“关联 App”，加入准确的 Bundle ID，例如 `com.example.game`。编辑器会同时保存当前设备画面的宽高；需要替换时点击“使用当前尺寸”，然后保存配置。也可以在设备检查器的 App 行上使用关联操作，此时会使用当前实时画面尺寸。

从 DeviceHub Mask 启动该 App 时，应用只会激活 Bundle ID 和当前画面宽高都完全匹配的已保存配置。因此同一个 Bundle ID 可以分别关联 iPhone 与 iPad 配置；只有 Bundle ID 与目标分辨率都相同的重复关联才会报告冲突。直接在设备上或由其他程序启动 App 不会触发这条桌面工作流。设备工作台的配置选择器始终可以手动切换已保存的当前配置。

原生配置格式当前为 `version: 2`。项目处于早期开发阶段，不读取 `version: 1` 配置，也不提供自动迁移；旧文件应移出配置目录后重新创建或从受支持来源重新导入。

## 导入格式

导入时必须明确选择来源，应用不会猜测格式。

| 来源 | 接受输入 | 转换行为 |
| --- | --- | --- |
| DeviceHub Mask | 最大 4 MiB 的 `version: 2` 配置 JSON | 保留映射、硬件快捷键、Bundle ID 和目标分辨率；保存前仍由后端完整校验 |
| scrcpy-mask | 最大 4 MiB、带 `original_size` 的 `0.0.1` JSON | 归一化坐标，把 Super 键名转换为 Meta，保留全部 13 类已识别控制器及嵌套字段；硬件快捷键和 App 关联为空 |
| PlayCover | 最大 1 MiB 的 XML `2.0.0` `.playmap` | 键盘按钮转为 SingleTap，键盘拖拽按钮转为 MouseCastSpell，键盘方向盘转为 DirectionPad，并以导入时的当前画面尺寸保存 Bundle ID 关联 |

PlayCover 鼠标区域、不支持或为负数的鼠标/手柄键码、非法坐标和不完整方向盘会被跳过，并计入导入结果。解析器拒绝 XML entity 与非标准文档声明，同时限制嵌套深度、节点数和模型数。

导入后的配置名来自文件名，会清理为合法字符并限制为 80 字符；发生重名时自动增加 `-import-N` 后缀。

## 导出与迁移

导出菜单包含两种不同契约：

- “DeviceHub Mask”导出完整配置，包括硬件快捷键和 Bundle ID 关联，适合备份或在 DeviceHub Mask 安装之间迁移。
- “scrcpy-mask”按编辑器当前源画面尺寸导出 `0.0.1` 映射 JSON，只包含控制器映射，不包含 DeviceHub Mask 的硬件快捷键和 App 关联。

当前不支持导出 PlayCover。导入导出兼容性不会加入 scrcpy Android 传输，也不会提供 PlayCover 手柄或鼠标输入源。

## 故障排查

| 表现 | 检查项 |
| --- | --- |
| 按键没有反应 | 确认处于映射模式、关闭编辑、聚焦应用、保存并激活目标配置，同时检查绑定不是空值 |
| 覆盖层高亮但游戏没有响应 | 检查持续时间、目标位置、触点 ID 所有权、五触点上限，以及更早的映射是否使用相同按键 |
| 一个按键似乎关联多个控件 | 删除重复物理按键绑定；运行时只允许第一个生效映射拥有该按键 |
| 两个并发动作中的一个消失 | 为它们分配不同触点 ID，并为鼠标直接触控预留容量 |
| 旋转后坐标错误 | 在游戏当前方向重新编辑，或分别维护横屏和竖屏配置 |
| 导入控件可见但不能使用 | 查看控制器表；部分 scrcpy-mask 字段以及 Script/JoyStick 行为只支持往返兼容 |
| PlayCover 提示跳过映射 | 鼠标区域、不支持的键码、非法坐标和不完整方向盘没有安全等价实现，因此会主动跳过 |
| 输入似乎卡住 | 松开按键、切换模式或页面，或重新聚焦窗口；这些转换都会发送完整释放。设备会话结束时应重新连接 |

报告可复现的运行时问题时，请提供配置导出、控制器类型、设备方向、源画面尺寸、编辑器显示的准确物理键码，以及仅覆盖复现时间窗口的 Debug 日志。配置可能暴露用户使用的 App 和操作习惯，分享前应先检查内容。
